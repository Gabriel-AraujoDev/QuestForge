# ⚔️ QuestForge

> Um sistema de RPG desenvolvido em **Node.js**, focado em praticar lógica de programação, manipulação de dados e interação através do terminal.

## 🎮 Sobre o projeto

O **QuestForge** é um projeto de RPG executado diretamente pelo terminal.

O jogador pode selecionar personagens, encontrar missões, receber recompensas, evoluir de nível e consultar informações do jogo.

O projeto está sendo desenvolvido de forma incremental, adicionando novas funcionalidades conforme o aprendizado.

## 🚀 Funcionalidades

* 👤 Sistema de jogadores
* ⚔️ Sistema de missões
* 🔎 Busca de jogadores e missões
* 🎯 Requisitos de nível para missões
* ⭐ Sistema de XP
* 💰 Sistema de moedas
* 🏆 Ranking de jogadores
* 📊 Estatísticas globais
* 📜 Histórico de missões
* 💾 Persistência de dados utilizando JSON
* 🖥️ Interação através do terminal

## 🛠️ Tecnologias

* **JavaScript**
* **Node.js**
* **JSON**
* **Git & GitHub**

## ▶️ Como executar

Clone o repositório e entre na pasta:

```bash
git clone <URL_DO_REPOSITORIO>
cd QuestForge
```

Execute o projeto:

```bash
node script.js
```

## 📚 Objetivo

Este projeto foi criado para colocar em prática conceitos de JavaScript e Node.js, principalmente:

* Arrays e objetos
* `find()`
* `filter()`
* `map()`
* `reduce()`
* `sort()`
* Funções
* Condicionais
* Manipulação de arquivos
* Leitura e alteração de JSON
* `import` e `export`
* Entrada de dados pelo terminal
* Organização de código
